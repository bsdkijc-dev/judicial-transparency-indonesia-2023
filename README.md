# Judicial Transparency Indonesia — FY 2023 Mahkamah Agung RI Financial Reconciliation

Structured, auditable, Google Sheets-ready (UTF-8 CSV, pure numeric fields) and Markdown dataset extracted from [*Laporan Keuangan Mahkamah Agung Republik Indonesia Tahun 2023 (Audited)*](https://drive.google.com/drive/folders/1OEorvUPXgSwqheqGk35B8EmD1u43vL7R) (signed 8 Mei 2024).

- `data/` — Six primary analytical tabs (`Summary_KPIs`, `LRA_Budget_Execution`, `Court_Escrows_Uang_Titipan`, `Grants_and_ThirdParty_Aid`, `State_Losses_TP_TGR_BPK`, `Capex_KDP_Projects`).
- `reconciliation/` — `financial_reconciliation_exceptions_2023.csv` and domain reconciliation reports.
- `reports/` — Executive audit summary, data quality assessment, and FY 2022–2023 comparability analysis.
- `metadata/` — Data dictionary, source inventory, accounting framework, and verification protocol.
